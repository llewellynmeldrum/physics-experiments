# Physics experiments
Some simple physics stuff with raylib for rendering. 

Starting with 2d, but goal is to implement this in my vulkan renderer in 3d. 

**v0.1 : 2d point-radius solver with fixed-size residency grid - able to simulate 3k objects @35fps (50fps w/ 2 residency cells per meter)** <br>
